# 第三步：导入公司和关系

在 bknd 目录执行：

```bash
node scripts/import-companies.mjs ~/Desktop/companies_1008.csv ~/Desktop/relationships_1008.csv
```

脚本使用 csv-parse 正确处理公司名称里的逗号和引号，先检查编码、数值和关系引用，再用事务导入。
公司编码已存在时跳过，不覆盖页面中修改过的数据；再次运行不会重复插入。
本地已导入公司和关系各 2000 条，第二次执行均新增 0 条。原始 CSV 未加入 Git。
账号管理员权限单独在本地授予，不能从公开注册接口自选；已有密码不变。

当前导入器检查自引用和缺失父公司，但尚未检查多节点循环；重新导入也不会同步修改过的 CSV。
演示用户创建和管理界面在后续步骤中完成。
