# AI聊天第6步：全局悬浮入口

## 实现
ftnd/src/features/ai-chat/components/chat-launcher.tsx 是悬浮入口，维护窗口开关。
chat-window.tsx 是浮窗：使用MUI，与工作台主题一致。关闭按钮或Escape可以关闭，并把焦点交回入口。
入口放在workspace-shell.tsx，所有登录后的工作台页面共享它。浮窗不是模态窗口，导航仍可使用；客户端路由切换时窗口状态保留。
不同屏幕使用自适应宽度和高度，窗口不依赖单个页面。

## 范围
本步完成入口、窗口和最近会话的只读历史加载：打开时经Next.js服务端代理读取数据库，关闭或刷新后再次打开会重新加载。
最多显示最近会话最早的1000条，更多数据仍保留在数据库并会显示提示。多会话切换、完整消息类型与Markdown渲染、发送和上传尚未接入。
第5步后端已有真实对话API，但本步尚未把发送接口连接到前端，页面不会假装能聊天。

## 查看
1. 打开Docker Desktop，在项目根目录运行 docker compose up -d --wait。
2. 在bknd运行 npm run start:dev；另一个终端在ftnd运行 npm run dev。
3. 登录后打开Dashboard，点击右下角“AI助手”；在窗口打开时切换Company、Order和User，观察入口及窗口。
4. 点击右上角关闭，重新打开；也可以在窗口内按Escape关闭。缩窄浏览器检查小屏布局。
5. 未登录的登录/注册页面不显示工作台入口。
6. 如果通过Swagger预先创建了会话和文本消息，再打开聊天窗口可看到最近会话内容；关闭重开或刷新后仍可读取。
