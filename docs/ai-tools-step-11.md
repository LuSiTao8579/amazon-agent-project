# AI Agent 第二周第十一步 · 公司折叠表和 Dashboard 卡片

## 一行公司数据如何显示

公司管理页从公司列表接口读取当前页。聊天从已保存的表格消息读取当次查询的行。两处都把公司交给 `CompanyTableRow`，由它展示名称、等级、国家和人均年营收。点击名称或展开按钮可以查看城市、成立年份、年营收和员工数量。用键盘聚焦按钮后，按 Enter 或空格也能切换。

每条聊天表格维护自己的已展开公司编码。React 用消息 ID 区分两份表格，用公司编码区分表内的行。即使同一家公司出现两次，两个按钮也会关联到各自的详情行。管理页通过额外的操作列提供编辑和删除。[共享公司行](../ftnd/src/components/company-table-row.tsx) · [聊天公司表](../ftnd/src/features/ai-chat/components/company-table-message.tsx)

人均年营收直接使用业务 Service 返回的值。小于 100 显示浅橙色，100 至不足 500 显示浅蓝色，500 及以上显示浅绿色。员工数为零时显示灰色的“不可计算”。标签最多保留两位小数，色阶按原值判断。[效率展示规则](../ftnd/src/components/revenue-per-employee.ts)

## 聊天窗口怎样容纳表格和看板

- 公司表和用户表都显示匹配总数、当前页、本页行数和每页条数。窄屏可以在表格内横向滚动；长表可以在表格内上下滚动，列标题保持可见。用户表与管理页共用姓名、邮箱、岗位、状态四列，状态显示为“启用”或“停用”。[聊天表格](../ftnd/src/features/ai-chat/components/result-table.tsx) · [用户单元格](../ftnd/src/components/user-table-cells.tsx)
- 看板页与聊天报表共用四张卡片及 K/M/B 格式。将鼠标停在缩写数值上可以查看完整数字。卡片按容器实际宽度排列，所以同一台电脑上，宽看板可以并排展示，窄聊天窗口可以逐张阅读。等级分布和成立年份累计趋势沿用看板图表。[指标卡](../ftnd/src/components/dashboard-metrics.tsx) · [消息渲染](../ftnd/src/features/ai-chat/components/message-renderer.tsx)

## 自己验收

1. 在同一会话连续两次发送“查公司，按公司编码升序，取前 100 家”。在第一份表格展开一家公司，第二份同名公司应仍然收起。再展开第二份、收起第一份，第二份的详情应保持可见。
2. 在公司管理页找到相同编码，比较上述四个详情字段、人均年营收的数值与背景色。若有零员工的记录，两处都应显示“不可计算”。
3. 用管理员账号发送“查用户，每页 10 条”，核对四列和分页说明。再查一个无匹配的姓名，仍应能看到匹配总数为 0 和每页条数。
4. 在同一会话发送“查看全部公司的 Dashboard 指标、等级分布和累计趋势”。在公司数据保持一致时，对照看板页四张卡的名称、数值和单位。将浏览器缩窄至 360 像素，检查卡片、图表、表格最后一行和最右一列。刷新并打开原会话，表格与报表应仍可查看。
